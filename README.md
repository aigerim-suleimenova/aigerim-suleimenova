## 🛠 Featured projects

**[Broadcaster Agent](https://github.com/aigerim-suleimenova/broadcaster-agent)**: a full-stack AI agent for broadcaster research and outreach.
A Pydantic AI agent streams typed generative-UI components to a Next.js client over the AG-UI protocol. A custom MCP server exposes the broadcaster tools, and Gmail OAuth handles outreach.
It was built agent-first with Claude Code (spec → implement → review) and tested with Playwright and pytest.

**[Applications](https://github.com/aigerim-suleimenova/claims)**: an internal web app for insurance underwriters (React/TypeScript, Node.js/Express, PostgreSQL).
It was built with **spec-driven development** using [OpenSpec](https://github.com/Fission-AI/OpenSpec). Every feature starts as a reviewed proposal (`proposal.md` → spec deltas → `design.md` → `tasks.md`) before any code is written.

**[Neon Snake](https://github.com/aigerim-suleimenova/neon-snake-famobi-challenge)**: a Phaser 3 + TypeScript browser game with Famobi SDK integration, gameplay analytics, a Node.js/Firestore backend and a React stats dashboard.

**[File Collaboration](https://github.com/aigerim-suleimenova/file_collaboration)**: real-time collaborative document editing with Vue 3, FastAPI, PostgreSQL and Yjs CRDTs over WebSockets.
